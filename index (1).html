Kendi Sunucuna Kur

1. Repoyu klonla
git clone https://github.com/kullaniciadi/zerith-security
cd zerith-security
2. Bağımlılıkları yükle
pip install -r requirements.txt
3. Sunucuyu başlat
uvicorn main:app --host 0.0.0.0 --port 8000
4. Tarayıcıda aç
http://localhost:8000
